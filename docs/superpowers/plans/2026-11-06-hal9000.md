# HAL 9000 Desk Companion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Firmware and a voice-generation tool that turn an M5Stack CoreS3 into a HAL 9000 companion: red eye, console screens on tap, walk-up greetings, shake complaints, a press-and-hold shutdown with "Daisy Bell", unprompted remarks and quiet hours.

**Architecture:** All decision-making lives in a pure C++17 library (`lib/hal_core`, no Arduino headers) tested on the Mac with PlatformIO's `native` environment. A thin Arduino/M5Unified layer in `src/` reads inputs (touch, proximity, IMU, clock), feeds them to `hal::Brain` once per loop, carries out the returned `Actions`, and draws the eye or a console screen into a PSRAM canvas at ~30 fps. A Python tool renders text lines into Alan-voice WAVs laid out for the SD card.

**Tech Stack:** PlatformIO, Arduino-ESP32, M5Unified/M5GFX, Unity (native tests), Python 3.11 + piper-tts 1.8.0 + ffmpeg (voice tool), `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-06-hal9000-design.md`

## Global Constraints

- Board: M5Stack CoreS3. PlatformIO env `cores3`: `board = m5stack-cores3`, `framework = arduino`, `lib_deps = m5stack/M5Unified`. Test env `native`: `test_framework = unity`, `-std=c++17`.
- `lib/hal_core` must compile without Arduino or ESP headers. Files are prefixed `hal_` and live in `namespace hal`.
- Audio format everywhere: WAV, 22 050 Hz, mono, 16-bit PCM.
- SD paths exactly as the spec: `/hal/config.txt`, `/hal/voice/{boot,reboot,tap,mine,greet/morning,greet/afternoon,greet/evening,shake,idle,plea,relief,daisy}/`, `/hal/screens/`.
- Config keys and defaults verbatim from the spec: `wifi_ssid=`, `wifi_password=`, `timezone=EST5EDT,M3.2.0,M11.1.0`, `quiet_start=22:00`, `quiet_end=07:30`, `volume=180`, `quiet_volume=90`, `idle_min_minutes=20`, `idle_max_minutes=60`, `greet_cooldown_minutes=10`, `shake_cooldown_seconds=20`, `proximity_threshold=300`, `hold_seconds=3`.
- Greeting buckets: morning 05:00–11:59, afternoon 12:00–16:59, evening 17:00–04:59. Unknown time → afternoon.
- Voice: Piper `en_GB-alan-medium`, `length_scale=1.2`, `noise_scale=0.5`, `noise_w_scale=0.6`; ffmpeg chain `asetrate=22050*0.96,aresample=22050,atempo=1.0417,lowpass=f=7500,bass=g=3:f=150,aecho=0.8:0.5:35:0.10,loudnorm=I=-16:TP=-1.5`.
- Content: original lines only. No verbatim lines from the film; at most three parody riffs on its best-known catchphrase. The only non-original text is the public-domain 1892 "Daisy Bell" chorus.
- Never commit generated audio (`sd/`), Piper models, or a filled-in Wi-Fi password. The repo's config template has empty Wi-Fi values.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Config saved by TextEdit:** UTF-8 BOM at the start and CRLF line endings → parsed exactly like a plain file. (Task 2)
2. **Wi-Fi password containing `#`, `=` or spaces:** taken verbatim (only surrounding whitespace trimmed); no comment stripping on `wifi_ssid`/`wifi_password`. (Task 2)
3. **macOS junk on the SD card:** `._001-foo.wav`, `.DS_Store`, `.Trashes` must be ignored; `HELLO.WAV` (uppercase) accepted. Copying from a Mac to FAT creates the `._` files. (Task 5)
4. **ffmpeg-written WAVs:** a `LIST` chunk before `data`, odd-sized chunks with a pad byte, and a truncated file (data size larger than the file) must still parse or be rejected cleanly, never read past the buffer. (Task 4)
5. **Quiet window edges:** across midnight (22:00–07:30: 22:00 quiet, 07:29 quiet, 07:30 not), a same-day window (13:00–15:00), and start == end (never quiet). (Task 1)

**Interfaces:**

- Produces:
  - `enum class hal::MotionEvent { None, Shake, Pickup, TipOver }`; `class hal::MotionDetector { hal::MotionEvent update(float ax, float ay, float az, uint32_t nowMs); }` (accel in g).
  - `class hal::ProximityEdge { explicit ProximityEdge(int threshold); bool update(int reading); }` — true once when reading ≥ threshold after having been below `threshold*6/10`.
  - `enum class hal::Folder { Boot, Reboot, Tap, GreetMorning, GreetAfternoon, GreetEvening, Shake, Idle, Plea, Relief, Daisy }`; `const char* hal::folderPath(hal::Folder)` (e.g. `"/hal/voice/greet/morning"`); `bool hal::isVoiceFile(const std::string& name)`.
  - `class hal::VoiceIndex { explicit VoiceIndex(uint32_t seed); void setFiles(hal::Folder, std::vector<std::string> names); void addFiles(hal::Folder, const std::string& dir, std::vector<std::string> names); bool pick(hal::Folder, std::string* path); bool at(hal::Folder, int i, std::string* path) const; int count(hal::Folder) const; }` — stores full paths (`dir + "/" + name`), filters with `isVoiceFile`, sorts by name; `pick` shuffles, `at` is name order (plea/daisy).

Motion algorithm (not determined by tests alone):
- Shake: a "peak" is a sample with `| |a| − 1 | > 0.8`; peaks closer than 60 ms count once; ≥ 3 peaks within 600 ms → `Shake`, then peaks reset.
- Rest vector: low-pass gravity `g = 0.9g + 0.1a`; when `| |a| − 1 | < 0.05` continuously for 2000 ms, rest = g.
- Tilt = angle between `g` and rest. ≥ 60° for 1000 ms → `TipOver`; 20°–60° for 700 ms → `Pickup`. After either, no Pickup/TipOver until a new rest is captured.

### Task 6: Brain (state machine)

**Files:**
- Create: `lib/hal_core/src/hal_brain.h`, `lib/hal_core/src/hal_brain.cpp`
- Test: `test/test_brain/test_main.cpp`

**Interfaces:**
- Consumes: `Config` (Task 2), clock rules (Task 1), `ShuffleBag::random` (Task 3), `MotionEvent`, `Folder` (Task 5).
- Produces:
  - `enum class hal::Mode { Booting, Idle, Speaking, Console, Pleading, Daisy, Dark }`
  - `struct hal::Inputs { uint32_t nowMs; bool touchDown; bool proximityEdge; hal::MotionEvent motion; bool audioPlaying; bool timeValid; int minuteOfDay; int hour; }`
  - `struct hal::Actions { bool play=false; hal::Folder folder=hal::Folder::Tap; int index=-1 /* -1 = shuffled pick */; bool stopAudio=false; bool newConsole=false; bool restart=false; int volume=0; bool quiet=false; }`
  - `class hal::Brain { Brain(const hal::Config&, uint32_t seed, bool afterShutdown); void setSequenceLengths(int plea, int daisy); hal::Actions tick(const hal::Inputs&); hal::Mode mode() const; float daisyProgress() const; }`

Behaviour, exactly the spec's table, with these pinned details:
- First tick: `Booting` → play `Reboot` if `afterShutdown` else `Boot`, mode `Speaking`.
- `Speaking` ends → `Idle` on the first tick with `audioPlaying == false` that is at least 200 ms after the play action (covers a missing file).
- Tap = touch down then up in < `holdSeconds*1000` ms. From Idle/Speaking: `stopAudio`, `newConsole`, play `Tap`, mode `Console`. In Console: same (skip). Console ends when ≥ 8000 ms since it started and audio not playing.
- Hold reaching `holdSeconds*1000` ms in Idle/Speaking/Console → `stopAudio`, mode `Pleading`, play `Plea` index 0. Each plea line that finishes while still held → next index. Release while Pleading → `stopAudio`, play `Relief`, mode `Speaking`. Last plea finished while held (or plea length 0) → mode `Daisy`, play `Daisy` index 0, then each next index when audio stops, touch ignored. After the last (or daisy length 0) → `Dark`; 5000 ms later → `restart`.
- `daisyProgress()` = (finished daisy lines + fraction of current by elapsed/expected 4000 ms, clamped) / daisy length; 1.0 in Dark.
- Walk-up: `proximityEdge` in Idle, not quiet, ≥ `greetCooldownMinutes` since last greet (or never) → play the bucket's greet folder (unknown time → afternoon), mode `Speaking`.
- Motion ≠ None in Idle/Speaking, ≥ `shakeCooldownSeconds` since last (or never) → `stopAudio`, play `Shake`, mode `Speaking`.
- Idle remark: in Idle, not quiet, `now ≥ nextIdleAt` and ≥ 300 000 ms since anything was last played → play `Idle`; schedule `nextIdleAt = now + nextIdleDelayMs(random(), idleMin, idleMax)`. First schedule at construction-time tick.
- Every tick: `quiet = timeValid && isQuietHours(...)`, `volume = quiet ? quietVolume : volume`.

### Task 8: First boot on the device — audio, voice library, plain eye

Needs the CoreS3 plugged in by USB-C and a FAT32 microSD card prepared with `make_voice.py --copy-to`.

**Files:**
- Create: `src/audio.h/.cpp`, `src/sd_voice.h/.cpp`, `src/main.cpp`

**Interfaces:**
- Consumes: `parseWav`, `loudnessEnvelope` (Task 4); `VoiceIndex`, `Folder`, `folderPath` (Task 5); `parseConfig` (Task 2).
- Produces:
  - `class Audio { bool playFile(const char* path); void stop(); bool isPlaying() const; uint8_t level() const; void setVolume(uint8_t v); }` — reads the whole file into PSRAM (`ps_malloc`), validates with `parseWav`, computes a 20 ms envelope, plays with `M5.Speaker.playRaw((const int16_t*)…, samples, rate, false, 1, 0, true)`; frees the previous buffer only after `M5.Speaker.isPlaying()` is false; `level()` is the envelope value at `millis() - start`. A file that fails to open or parse returns false and prints `skip <path>: <reason>` to Serial.
  - `bool loadVoiceIndex(hal::VoiceIndex&)` — lists each folder with `SD.open(dir).openNextFile()`, adds `/hal/voice/mine` into `Tap`.
  - `hal::Config loadConfig()` — reads `/hal/config.txt` (defaults if absent), prints warnings to Serial.
- `main.cpp` (this task): `M5.begin`, `SD.begin(GPIO_NUM_4, SPI, 25000000)`, load config and voices, play a Boot line, draw a static red circle; tap plays a random Tap line; Serial prints folder counts.

### Task 11: Sensors, clock and full brain wiring

**Files:**
- Create: `src/proximity.h/.cpp`, `src/net_time.h/.cpp`
- Modify: `src/main.cpp`

**Interfaces:**
- Consumes: `hal::Brain`, `hal::MotionDetector`, `hal::ProximityEdge` and everything above.
- Produces:
  - `bool proximityBegin(); int proximityRead();` — LTR-553 at I²C `0x23` via `M5.In_I2C`: write `0x81 = 0x03` (PS active), `0x82 = 0x7F`, `0x83 = 0x08`, `0x84 = 0x00`; read 11-bit value from `0x8D` (low) / `0x8E` (high, mask `0x07`).
  - `bool syncTime(const hal::Config&, uint32_t timeoutMs)` — `WiFi.begin`, `configTzTime(tz, "pool.ntp.org", "time.nist.gov")`, wait for year ≥ 2025, write UTC to `M5.Rtc`, then `WiFi.disconnect(true); WiFi.mode(WIFI_OFF)`. `void restoreTimeFromRtc(const hal::Config&)` — RTC (UTC) → `settimeofday`, `setenv("TZ")`, `tzset()`.
- `main.cpp` final loop: `M5.update()` → build `hal::Inputs` (touch from `M5.Touch.getCount()`, proximity edge, `MotionDetector.update(M5.Imu accel)`, `audio.isPlaying()`, local time) → `brain.tick()` → execute actions (`stop`, `play` via `index < 0 ? pick : at`, `consoles.next`, `setVolume`, `ESP.restart()` with an `RTC_NOINIT_ATTR` magic flag for `afterShutdown`) → draw console when `mode()==Console`, else eye. Time sync at boot (eye shows meanwhile, 15 s timeout) and daily at 03:00. Serial at 2 Hz: `prox=<n> acc=<x,y,z> mode=<m> quiet=<0|1>`.
