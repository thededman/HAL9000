# HAL 9000 Camera (v0.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the CoreS3 front camera to HAL: a tiny live preview beside the eye, walk-up greetings when someone steps into view, and a "Visual Analysis" console screen with its own camera lines.

**Architecture:** The arrival decision and the new settings are pure logic in `lib/hal_core`, tested natively. A `src/camera` module polls the GC0308 at ~15 fps and exposes the preview sprite, a motion score, a moving-area box and the latest frame. Arrivals feed the Brain's existing walk-up input (OR with the wave), so the Brain is unchanged.

**Tech Stack:** PlatformIO (`~/.platformio/penv/bin/pio`), Arduino-ESP32 3.3.12 `esp_camera`, M5Unified/M5GFX, Unity, Python voice tool.

**Spec:** `docs/superpowers/specs/2026-11-06-hal9000-camera-design.md` (builds on `2026-11-06-hal9000-design.md`)

## Global Constraints

- Camera config exactly as the spec's spike findings: `pin_xclk=-1`, SCCB 12/11, D0–D7 = 39,40,41,42,15,16,48,47, VSYNC 46, HREF 38, PCLK 45, QQVGA RGB565, `fb_count=2`, PSRAM, `CAMERA_GRAB_LATEST`; init wrapped in `M5.In_I2C.release()` … `M5.In_I2C.begin()`.
- Frames never leave RAM: no saving, no network.
- New config keys and defaults: `camera=on`, `camera_preview=on`, `camera_motion_threshold=20` (1–255). Booleans: on/off, yes/no, true/false, 1/0, any case.
- Arrival: settled = score < threshold/2 for 20 000 ms; arrival = score ≥ threshold on 2 consecutive updates while settled; fires once, then needs a new 20 s settle. Wrap-safe time.
- Preview: 80×60 at (240,180); not shown in Console, Daisy or Dark.
- New voice folder `/hal/voice/camera` (`Folder::Camera`, appended last in the enum), ~20 original lines; empty → Visual Analysis plays `tap/`.
- Native tests run with `pio test -e native`; device builds with `~/.platformio/penv/bin/pio`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Room lights switching on or off** produce one huge score spike → at most one arrival, then the room must settle again (Task 2).
2. **Auto-exposure hunting in a dim room** keeps scores hovering around the threshold → the 20 s settle rule stops repeated arrivals (Task 2).
3. **`camera=On`, `YES`, `maybe`** → case-insensitive booleans; junk → default + warning (Task 1).
4. **`millis()` wrap during the 20 s settle** → still settles and fires correctly (Task 2).
5. **Camera fails to start** (or `camera=off`) → no preview, no arrivals, Visual Analysis absent from the rotation, nothing calls into `esp_camera` (Tasks 4–5).
